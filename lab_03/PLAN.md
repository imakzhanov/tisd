# Лабораторная №3. Разреженные матрицы. План

**Вариант 2** (16 % 5 + 1): сложение двух матриц в формате **CSC**, результат тоже в CSC.
Для сравнения - обычное сложение на статических массивах.

## Принятые по умолчанию решения (можно поменять)
- элементы матриц: `int`;
- максимальный размер: 1000 x 1000;
- обычные матрицы - статические массивы (`static int m[1000][1000]`), CSC - динамическая память;
- язык C99, сборка через `Makefile`, файлы: `src/*.c`, `inc/*.h`.

## Структура папки
```
lab_03/
  Makefile        make release | debug | run | clean
  inc/            заголовки (.h)
  src/            исходники (.c)
  data/           заранее подготовленные матрицы для тестов
```

## Модули (inc/*.h + src/*.c)
| модуль | что делает |
|---|---|
| `errors` | коды возврата (как в lab_02) |
| `dense` | обычная матрица в статическом массиве: обнуление, ввод/вывод, сложение |
| `csc` | структура `Csc {rows, cols, nnz, *a, *ia, *ja}`: создание, освобождение, вывод в виде трёх массивов |
| `csc_add` | сложение двух CSC по столбцам (слияние строк), результат в CSC |
| `convert` | обычная матрица <-> CSC (нужно для вывода и проверки) |
| `gen` | случайное заполнение с заданным процентом ненулевых |
| `input` | ввод: с клавиатуры (координатами `строка столбец значение`), из файла, с проверками |
| `output` | вывод: CSC всегда, обычной таблицей только если размер <= 30x30 |
| `bench` | замеры времени и памяти обоих способов |
| `menu` | меню и диалог с пользователем |
| `main` | запуск меню |

## Алгоритм сложения CSC
Для каждого столбца j: взять куски `A1/IA1` и `A2/IA2` (границы по `JA`), слить по возрастанию номера строки.
Одинаковая строка - значения складываются, сумма 0 не записывается. После столбца записать в `JA` результата текущую длину.
Результат создаётся с запасом nnz1 + nnz2 и при желании уменьшается.

## Меню
1. Ввести матрицу A (клавиатура, координатами / из файла / случайно с %)
2. Ввести матрицу B (так же)
3. Показать A и B (CSC; до 30x30 ещё и таблицей)
4. Сложить в формате CSC и показать результат
5. Сложить обычным способом и показать результат
6. Сравнить время и память (один запуск с выбранным размером и %)
7. Серия замеров для отчёта (размеры и проценты в таблицу)
0. Выход

## Проверки и обработка ошибок
Неверный ввод, пустой ввод, выход за границы, размеры вне 1..1000, процент вне 0..100, несовпадение размеров A и B, нулевой результат (сообщение), полностью заполненные матрицы, освобождение памяти при выходе.

## Замеры (для отчёта)
- размеры: 10, 100, 500, 1000;
- заполненность: 1, 5, 10, 20, 30, 40, 50, 70, 100 %;
- время: многократные повторы и среднее (`clock_gettime`), память: размер обычной матрицы и размер CSC (`sizeof`), найти % при котором CSC перестаёт быть выгодным.
